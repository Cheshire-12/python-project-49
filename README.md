# Brain Games
### About the project
This is a brain training game project. It consists of five games: "Calculator," "Parity Check," "Greatest Common Divisor (GCD)," "Arithmetic Progression," and "Is a Number Prime?" The project was created by Heklest student Andrey Vedenkin.

### Setup
```bash
make install
```
### Start play 
Game: "Calculator"
```bash
brain-calc
```
Game: "Parity Check"
```bash
brain-even
```
Game: "Greatest Common Divisor (GCD)"
```bash
brain-gcd
```
Game: "Is a number prime?"
```bash
brain-prime
```
Game: "Arithmetic Progression"
```bash
brain-progression
```
